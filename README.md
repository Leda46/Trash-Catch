# Trash-Catch

Description

With this project I hope to raise awareness to littering and to encourage people to try protect the planet by not throwing away trash. In my game the player has to move a customisable trash can to catch the pieces of trash falling from the air. For each piece caught they get one point added to their score. The game ends after 60 seconds and the player is shown their score and they can move back to the start screen with the Back to Start button where they can check the rules, customise their bin or play again.

Features
- Start screen with multiple choices of buttons
- Customisable bin
- Clouds moving in the background during the game
- A rules screen in case they don't know the game

How to Play
- Start the game using the buttons
- Move teh bin using the arrow keys
- Try catch as much trash as possible
- Have fun customizing your bin!
- Good luck!
